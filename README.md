# 🎓 Student Number Approval Portal  
### Human-Computer Interaction (HCI) Project

## Overview

The **Student Number Approval Portal** is a front-end prototype designed to streamline the student admissions feedback and approval process at the University of Jordan.

The existing manual system led to delays, inefficiencies, and costly administrative errors.  
Our goal was to design a **user-centered, intuitive, and structured approval system** that enhances decision-making for department heads, deans, and university administrators.

This project focuses on applying **Human-Computer Interaction (HCI) principles** to create an efficient and accessible digital solution.

---

## Objectives

- Improve the efficiency of the student number approval workflow  
- Reduce administrative delays and human errors  
- Create a role-based, structured decision-making interface  
- Design a user-friendly and accessible experience  

---

## User-Centered Design Process

We followed a structured HCI methodology:

- Stakeholder interviews (Heads of Departments, Deans, Vice Presidents)
- Task analysis & requirement gathering
- Low-fidelity wireframes
- Medium-fidelity prototypes
- High-fidelity interactive prototype (Figma)
- Heuristic evaluation
- Cooperative usability evaluation
